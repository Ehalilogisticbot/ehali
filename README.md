# ЕХАЛИ — Telegram-бот

Базовая версия бота для заявок на грузоперевозки.

## Что умеет
- Главное меню
- Заказ машины
- Расчёт стоимости (пока собирает заявку без автоматического тарифа)
- Услуги
- Для бизнеса
- Контакты
- Пошаговый сбор заявки
- Отправка заявки админу Telegram ID 952300757

## Запуск локально
1. Установить Python 3.11+
2. В терминале:
   pip install -r requirements.txt
3. Задать переменную BOT_TOKEN:
   Windows PowerShell: $env:BOT_TOKEN="ТОКЕН"
   macOS/Linux: export BOT_TOKEN="ТОКЕН"
4. Запустить:
   python main.py

Для постоянной работы используйте веб-хостинг с webhook.
